# V3 单章分析规则

此文件用于维护语义口径；实际单章任务只携带其中的精简规则，不把整份文档塞入请求。

## 原文与双语块

- `blocks[].text_en` 按顺序拼接必须逐字符等于当前 `source/chapters/pNN.txt`。
- 不修正原文拼写、标点、大小写、换行或语法。
- 同一英文内容只能出现一次；证据只引用块编号。
- 对话与叙述/动作混在一段时可拆成多个连续块，但不能移动字符。
- 非分隔块必须有中文翻译；翻译忠实、通顺，不补写剧情。
- 对话必须有 `speaker_ref`。无法判断时使用 `unknown` 并建立待确认问题。

## Scene 与 Beat

出现以下变化时新建 Scene：

- 具体地点变化。
- 内景与外景变化。
- 时间线有可识别的跳跃。
- 现实、梦境或回忆层级变化。

同一时空内出现以下变化时新建 Beat：

- 角色目标或策略改变。
- 冲突明显升级、缓和或逆转。
- 关键信息揭示。
- 权力关系改变。
- 重大情绪转折。

场景名使用“归属地点·具体空间”。原文没有时间或内外景证据时使用 `UNKNOWN` 并建立问题，不猜测。

## 角色、地点与事实

- 登记有明确姓名、有台词、稳定身份或高频复现的群众角色。
- 一次性无名群体可作为 crowd；管家、园丁等持续身份可作为 recurring_role。
- 实际行动/现场说话、回忆、梦境、仅被提及必须分开。
- 人物事实字段为年龄、性别、种族、身份、外貌、发型、体型、特殊标记、服装、性格。
- 地点事实只记录空间、环境、陈设和剧情中的状态变化。
- 只保存原文明示事实或用户确认，不为完整性强行推断。
- 已有实体优先复用任务包中的 ID；疑似同一实体不得静默合并。

## 资产候选

- 普通角色与具体地点由全局程序自动列入候选。
- 单章 Agent 只额外记录剧情明确要求区分的服装、道具或视觉状态变体。
- 不填写色板、造型方案、镜头、光线、构图、建筑风格或提示词。
- 是否制作、合并、拆分或排除由用户决定。

## 不确定项

只有会影响制片、翻译、角色归档、场景归档或资产范围的问题才进入 `issues`。全文后仍无证据时，用户可以确认“接受未知”，无需回写早期章节。

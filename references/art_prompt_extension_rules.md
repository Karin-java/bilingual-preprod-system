# 美术提示词扩展规则

## 输入边界

- 每次只处理任务包中的一个 Scene，不重新读取整本原文。
- 角色统一使用永久角色 ID；别名和旧 ID 由核心角色登记解析。
- 只使用 `scene_facts`、`characters` 和双语 `evidence` 中已有的信息。
- `unresolved` 中的项目不得自行补全；若创作必须选择，应明确标为创作建议，不能伪装成剧情事实。
- `presence_type = mentioned` 的角色只被提及，不应自动画入场景。

## 默认交付

输出一个清洗后的 Markdown 文件，至少包含：

1. 场景目标与已确认视觉事实。
2. 在场角色及已确认外观信息。
3. 可直接交给图像生成工具的中文提示词。
4. 不得虚构的待确认项。

同一内容不同时生成 DOCX。用户明确选择该 Markdown 后，才执行单文件 DOCX 转换。

扩展不得覆盖 `source/`、`data/`、现有中英剧本或角色统计文件。
